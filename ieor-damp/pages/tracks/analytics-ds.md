## Who it suits

- You enjoy working with data and coding, and want an analytics, data science or ML role (or an MS in data science).
- You are ready to spend time outside courses on projects and practice.

## Semester by semester

| Semester | Courses | Why |
|---|---|---|
| 3 (Autumn) | IEOR core; start the DS (or CMInDS) minor if eligible | Get the minor sequence started early |
| 4 (Spring) | IEOR core; **IE 506** Machine Learning: Principles and Techniques | ML foundations from an IEOR angle |
| 5 (Autumn) | **IE 621** Probability and Stochastic Processes I; minor course | Probability depth helps in ML interviews |
| 6 (Spring) | **IE 617** Online Machine Learning and Bandit Algorithms or **IE 620** Reinforcement Learning Algorithms; minor course | Sequential decision-making is where IEOR and ML meet |
| 7–8 | Remaining minor courses; BTP with a data component | A project with real data |

## Minor or honours

- **DS or CMInDS minor**: check which one your batch is eligible for, the application window, and whether IEOR courses double-count (usually they don't). See the [FAQs]({{ '/faq/#minors' | relative_url }}).
- CS courses taken as IE (data structures, algorithms) are worth it if you want ML engineering rather than analytics.

## Skills to build alongside

- Python (pandas, scikit-learn), SQL, and one visualisation tool.
- Basic ML: regression, trees, cross-validation; be able to explain them.
- Two or three projects on real data, with the code on GitHub.

## Opportunities to watch

- Amazon ML Summer School, Flipkart GRiD and Google Summer of Code: see the [Radar]({{ '/radar/?kind=programme' | relative_url }}).

## Honest effort note

A minor adds about one course per semester. If that pushes your CPI down, a "lighter" version works too: take IE 506 plus two ML electives as IE, and spend the saved time on projects.
